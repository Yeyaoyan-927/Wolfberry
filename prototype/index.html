杞杞市 · Goji Market 设计原型 v1.0

交易端 + 后台端，11 个核心页面

依据《枸杞交易平台需求文档 v4.0》绘制。重点看三处：商品详情页的「AI 外观评估卡」、后台的「审核工作台」、卖家发布时的「等级差异提示」——这三个界面承载了平台防"图文不符"的核心机制。

这套原型故意没做的

  • 没有做登录页——流程简单，评审时看价值页更重要
  • 没有做支付、物流轨迹页面——需求已明确排除
  • 没有拉真实图片，用色块占位，落地时替换为实拍图

落地到 Vue 3 的映射

  • assets/app.css 的令牌映射为 Element Plus 主题变量
  • 每个 .card 对应一个 <el-card> 或自定义容器
  • 审核三栏用 CSS Grid，不用 flex 百分比计算
  • 等级/差异标记封装为 <GradeTag> <DiffFlag> 两个组件
