### 定位最终版本
**仅图像外观辅助筛查**：坏果率 / 霉变率 / 油果率 / 杂质率 / 粒数。
不检测硫（二氧化硫）、水分、多糖、农残、重金属 —— 已写入三处免责文案、报告"未检测项"清单、问答拦截规则。

### v3.0 技术决策（后续开发必须遵守）
1. 推理：YOLOv8n/s-seg 导 **ONNX**，ONNX Runtime **CPU**，短边 1024 降采样；原图仅存档不推理。
2. 单 worker 串行消费任务表，推理并发固定 1；队列深度 20。
3. 部署：venv + **NSSM** 三服务（api/worker/mysql），无 Docker；FastAPI 托管两套前端 dist。
4. V1 **不接 LLM**：结果说明用模板拼接；问答降级为 MySQL FULLTEXT 条款速查（只返原文，不生成）。
5. V1 后台只做 5 项：用户角色 / 任务排查 / 阈值配置 / 审计 / 模型版本记录。
6. 删除多模态冲突仲裁，改为**单模态图像有效性判定**（L1 轻量门禁 + L2 模型门禁两级分离）。
7. 多图汇总必须"先合并计数再算比率"，禁止对各图比率取算术平均；类别互斥优先级 霉变>坏果>油果>杂质>正常。
8. 粒径不出 mm，只出"相对粒径指数"（无标定板）。
9. 性能口径：端到端典型 ≤20s、P95 ≤30s；推理耗时与接口耗时分开报，不得合并。
10. 存储：图片约 260GB/年，512GB 盘只够 1.5 年 → 必须第二块盘或原图保留 6 个月。

### 关键风险（已写入文档）
- 无拍摄箱 → 精度不稳 → 靠附录 D 拍照指引 + 置信提示 + 强制复核兜底，不承诺精度
- 单机单点 → 无高可用 → UPS + 每日备份 + RTO 4h + 明确告知业务方
- NSSM 服务被杀毒/系统更新干掉 → 白名单 + 关闭自动更新 + 2 分钟监控告警
- 光谱残留清理不彻底 → 第 13 章 18 条清理清单，逐条验收
